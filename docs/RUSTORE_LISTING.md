## 3. Полное описание приложения (для RuStore)

```text
Трудно уснуть? Просыпаетесь среди ночи или чувствуете разбитость по утрам?

«Сомния» — это доказательное приложение для восстановления глубокого и спокойного сна без снотворных, созданное на основе протоколов когнитивно-поведенческой терапии инсомнии (CBT-i / КПТ-Б).

В мировой медицине и сомнологии метод CBT-i признан золотым стандартом первой линии в преодолении бессонницы. Приложение восстанавливает естественные биоритмы и устраняет ночную тревогу с помощью научно выверенных поведенческих техник.

ЧТО ВНУТРИ ПРИЛОЖЕНИЯ:

🌙 1. Утренний дневник сна
Всего 2 минуты утром для фиксации ключевых параметров ночи: время в кровати (TIB), чистое время сна (TST) и клиническая эффективность сна (Sleep Efficiency, SE %).

⏱️ 2. Терапия ограничением сна (Sleep Window)
Интеллектуальный сомнологический алгоритм анализирует ваш дневник за неделю и рассчитывает индивидуальное «окно сна». Это помогает накопить естественное «давление сна» и сделать ночной сон непрерывным.

🚪 3. Правило 20 минут (Стимульный контроль)
Не можете уснуть? Не ворочайтесь в постели. Запустите ночной компаньон: он работает в мягком тихом фоне без тикающих секунд (защита от часовой тревоги / clock-watching) и подскажет, чем заняться в другой комнате до появления естественной сонливости.

🌬️ 4. Дыхательная практика 4-7-8
Плавная медитативная анимация для быстрого снижения частоты пульса, снятия вегетативного напряжения и мягкого погружения в дремоту.

🎧 5. Звуки природы для засыпания
8 высококачественных бесшовных аудиодорожек: мягкий дождь, ночной лес, морской прибой, лесной ручей, сверчки, белый шум и тибетские поющие чаши. Встроен таймер сна с плавным угасанием звука (fade-out) за 30 секунд до конца.

📊 6. Клинический тест бессонницы (ISI)
Стандартизированный опросник индекса выраженности инсомнии (7 вопросов, от 0 до 28 баллов) для точной оценки симптомов и отслеживания динамики улучшений.

🧠 7. Работа с тревожными мыслями о сне
Разбор распространенных катастрофических убеждений («Я обязан спать 8 часов», «Бессонница разрушит мой день») и замена их на доказанные факты.

📋 8. Экспорт отчета для врача-сомнолога
Формирование сводной таблицы показателей сна за 14 или 30 дней в один клик для демонстрации врачу на приеме.

ПОЛНАЯ ПРИВАТНОСТЬ (100% OFFLINE-FIRST):
• Приложение не требует регистрации и создания аккаунта.
• Все медицинские записи хранятся исключительно в памяти вашего телефона.
• Работает без интернета — в самолете, на даче или при плохой связи.
• В любой момент вы можете удалить все данные одной кнопкой.

Внимание: Приложение носит психообразовательный и поведенческий характер и не заменяет очную консультацию врача-сомнолога.
```

## 5. Примечание для модератора RuStore

```text
Уважаемая команда модерации RuStore!

Приложение «Сомния» представляет собой информационно-образовательный инструмент и дневник сна на базе доказанного метода когнитивно-поведенческой терапии бессонницы (CBT-i).

Особенности сборки:
1. Приложение полностью Offline-First: не собирает и не передает персональные данные на внешние серверы. Все записи хранятся локально в SharedPreferences/SQLite.
2. При первом запуске пользователю в обязательном порядке отображается экран информированного согласия и клинических противопоказаний.
3. Разрешения FOREGROUND_SERVICE_MEDIA_PLAYBACK и WAKE_LOCK используются исключительно для бесшовного воспроизведения фоновых звуков природы и работы таймера сна при заблокированном экране.
4. Отсутствуют встроенные покупки, сторонние трекеры и реклама.
```

## 6. Команды для сборки релизной версии

Для сборки готового установочного файла выполните в терминале в папке `d:\ANTI\somnia`:

### Сборка универсального APK (для RuStore):
```bash
flutter build apk --release
```
*Файл будет сохранен по пути: `build/app/outputs/flutter-apk/app-release.apk`*

### Сборка AAB (для Google Play):
```bash
flutter build appbundle --release
```
*Файл будет сохранен по пути: `build/app/outputs/bundle/release/app-release.aab`*
