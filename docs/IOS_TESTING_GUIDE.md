# Как протестировать «Сомнию» на iPhone без релиза в App Store

Apple строго контролирует установку приложений, но для тестирования **без публикации в App Store и без покупки платного аккаунта разработчика за $99** есть 4 проверенных способа:

---

### Вариант 1: Бесплатная установка через Windows с помощью Sideloadly (Самый простой и популярный)

Этот способ позволяет установить приложение прямо на ваш iPhone с помощью обычного компьютера на Windows и вашего личного бесплатного Apple ID.

#### Что понадобится:
1. iPhone и провод Lightning / Type-C к компьютеру.
2. Бесплатная утилита **[Sideloadly](https://sideloadly.io/)** (устанавливается на Windows).
3. iTunes и iCloud для Windows (скачанные напрямую с сайта Apple, не из Microsoft Store, как требует Sideloadly).

#### Пошаговые действия:
1. **Получите файл `somnia.ipa`:**
   - В вашем репозитории на GitHub во вкладке **Actions** запустится экшен `Build iOS IPA for Sideloading`.
   - Скачайте готовый артефакт **`somnia-ios-ipa`** (внутри архив с файлом `somnia.ipa`).
2. **Установите через Sideloadly:**
   - Подключите iPhone к компьютеру через USB и нажмите «Доверять этому компьютеру» на экране телефона.
   - Запустите **Sideloadly**. В поле «iDevice» отобразится ваш телефон.
   - Перетащите файл `somnia.ipa` в окно Sideloadly.
   - В поле «Apple ID» введите ваш обычный Apple ID (почту, привязанную к телефону).
   - Нажмите **Start**. Sideloadly сам подпишет приложение вашим личным бесплатным сертификатом разработчика и установит его на iPhone.
3. **Первый запуск на iPhone:**
   - Перейдите в: **Настройки ➔ Основные ➔ VPN и управление устройством**.
   - Нажмите на ваш Apple ID и выберите **«Доверять»**.
   - На iOS 16/17/18 также включите **Режим разработчика**: *Настройки ➔ Конфиденциальность и безопасность ➔ Режим разработчика (в самом низу)* и перезагрузите телефон.
   - Теперь иконка «Сомния» запускается как полноценное нативное приложение!

> **Важно:** Бесплатный сертификат Apple действует **7 дней**. Через неделю приложение достаточно снова подключить к ПК и нажать Start в Sideloadly (все данные дневника и прогресс сохранятся).

---

### Вариант 2: Запуск как веб-приложение (PWA) в Safari — мгновенно и без проводов

Если вы хотите прямо сейчас пощупать интерфейс, калькулятор сна, тесты ISI/DBAS и визуальную часть на экране iPhone:
1. Соберите проект под Web или разверните на GitHub Pages / Vercel.
2. Откройте ссылку в **Safari** на iPhone.
3. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) ➔ **«На экран "Домой"»**.
4. На рабочем столе появится иконка «Сомния». При запуске она открывается на весь экран без адресной строки браузера, сохраняя данные в локальное хранилище телефона.

---

### Вариант 3: Официальный TestFlight (Если есть платный Apple Developer Account)

Если у вас или вашей компании есть платный аккаунт **Apple Developer Program ($99/год)**:
1. Загрузите сборку в App Store Connect.
2. Добавьте свой email в раздел **TestFlight ➔ Внутреннее тестирование**.
3. На iPhone установите приложение **TestFlight** из App Store.
4. Вы сможете тестировать приложение в течение 90 дней, получать обновления по воздуху и делиться ссылкой с 10 000 тестеров без прохождения публичной модерации App Store.

---

### Вариант 4: Через Mac и кабель (Xcode)

Если у вас или знакомого есть Mac:
1. Откройте папку `somnia/ios` в **Xcode**.
2. В разделе **Signing & Capabilities** выберите бесплатный `Personal Team` со своим Apple ID.
3. Подключите iPhone кабелем, выберите его в списке устройств сверху и нажмите кнопку **Run ▶**.
4. Приложение установится на устройство за 1 минуту.
